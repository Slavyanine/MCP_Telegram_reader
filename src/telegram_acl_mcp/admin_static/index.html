КОНФИГУРАЦИЯ СЕРВЕРА

Аккаунт, чаты и обработка

Изменения применяются с перезапуском MCP-службы.

Черновик
Рабочая конфигурация изменилась вне панели. Сбросьте черновик перед продолжением.

01 · Telegram-аккаунт

Аккаунт ещё не проверен. Загрузите список чатов.

Новая авторизация подготовит отдельную сессию и базу индекса. Работающий сервер переключится только после применения. Для отмены уже завершённого входа используйте «Сбросить черновик».

02 · Разрешённые чаты

Отметьте чаты и задайте ключи, по которым к ним будет обращаться MCP.

ДоступЧат в TelegramКлюч MCP · keyНазвание · title

Чаты не найдены. Загрузите список или измените фильтр.

Технические параметры чата заполняются автоматически. Загрузка следующей страницы сохраняет ваш выбор.

03 · Режимы обработки

Выключение режимов сохраняет базу и готовые расшифровки. Смена провайдера не запускает повторную расшифровку готовых результатов или заданий с ошибкой.

Проверка изменений

MCP-служба будет перезапущена. При включённой индексации данные исключённых чатов будут удалены из активного индекса. Перед применением создаётся резервная копия.
